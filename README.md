# Python — Estudos

Repositório criado para registrar minha evolução nos estudos de Python, reunindo exercícios e pequenos projetos desenvolvidos durante o aprendizado.

## Primeiro projeto: Pedra, Papel e Tesoura

Este foi meu primeiro projeto em Python: uma versão no terminal do jogo Pedra, Papel e Tesoura.

O jogador escolhe entre pedra, papel ou tesoura, enquanto o computador faz uma escolha aleatória. O projeto foi desenvolvido para praticar a comparação entre as escolhas e a apresentação do resultado de cada rodada.

### Conceitos praticados

- Estruturas condicionais (`if`, `elif` e `else`)
- Laços de repetição
- Entrada e saída no terminal
- Tratamento básico de texto digitado pelo usuário
- Coleções de dados
- Geração de escolhas aleatórias

### Como executar

1. Tenha o Python 3 instalado.
2. Clone este repositório ou baixe os arquivos.
3. No terminal, entre na pasta do projeto.
4. Execute o arquivo `tesoura_pedra_papel.py` com Python.

### Objetivo de aprendizado

Mais do que criar um jogo completo, este projeto marca o início dos meus estudos práticos em Python. Ele foi usado para entender como decisões, repetições e entradas do usuário funcionam em conjunto.
