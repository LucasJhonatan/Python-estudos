## Primeiro projeto: Pedra, Papel e Tesoura

Este foi meu primeiro projeto em Python: uma versão no terminal do jogo Pedra, Papel e Tesoura.

O jogador escolhe entre pedra, papel ou tesoura, enquanto o computador faz uma escolha aleatória. O projeto foi desenvolvido para praticar a comparação entre as escolhas e a apresentação do resultado de cada rodada.

### Conceitos praticados

- Estruturas condicionais (`if`, `elif` e `else`)
- Laços de repetição
- Entrada e saída no terminal
- Tratamento básico de texto digitado pelo usuário
- Coleções de dados
- Geração de escolhas aleatórias

### Como executar

1. Tenha o Python 3 instalado.
2. Clone este repositório ou baixe os arquivos.
3. No terminal, entre na pasta do projeto.
4. Execute o arquivo `tesoura_pedra_papel.py` com Python.

### Objetivo de aprendizado

Mais do que criar um jogo completo, este projeto marca o início dos meus estudos práticos em Python. Ele foi usado para entender como decisões, repetições e entradas do usuário funcionam em conjunto.

## Ideias para próximos projetos

Ainda estou no começo, então quero ir sem pressa: fazer projetos pequenos, pegar prática e ir melhorando aos poucos. Algumas ideias para tentar depois:

1. **Jogo de adivinhação** — o computador escolhe um número e você tenta acertar. Ele avisa se o seu palpite foi maior ou menor. Aqui dá para praticar `while`, `if` e números aleatórios.
2. **Calculadora no terminal** — você digita dois números, escolhe uma operação e vê o resultado. Boa para treinar funções, `if` e conferir se a entrada está certa.
3. **Lista de tarefas simples** — dá para adicionar, ver e remover tarefas. É uma forma legal de praticar listas, laços e menus.
4. **Conversor de unidades** — pode converter temperatura, quilômetros para milhas ou qualquer outra medida. Ajuda a treinar contas e funções.
5. **Quiz de perguntas e respostas** — mostra perguntas, confere as respostas e conta os pontos no final. Dá para praticar listas, laços e contadores.
6. **Agenda de contatos** — você pode cadastrar e procurar contatos. Depois, dá para salvar tudo em um arquivo `.txt` ou `.json`.
7. **Gerador de senhas** — cria senhas aleatórias do tamanho que você escolher. Ótimo para mexer com strings, listas e o módulo `random`.

Não preciso fazer tudo de uma vez. A ideia é escolher um projeto, fazer uma primeira versão funcionar e depois ir melhorando.

## Dicas para quem está aprendendo Python

- **Faça um pouco todo dia.** Mesmo 20 ou 30 minutos já contam. O mais importante agora é criar constância.
- **Digite o código.** Copiar um exemplo ajuda a entender, mas escrever e mudar partes dele é o que faz a lógica ficar mais clara.
- **Errou? Ótimo: investigue.** Leia a mensagem de erro com calma, tente entender a linha indicada e pesquise o que não souber. Isso também é programar.
- **Quebre o problema em partes pequenas.** Antes de pensar no projeto inteiro, faça uma função ou uma etapa funcionar.
- **Dê nomes claros às variáveis e funções.** Um código fácil de ler já é um código muito melhor.
- **Termine projetos simples.** Uma calculadora que funciona ensina mais do que um projeto gigante que fica parado pela metade.
- **Revise códigos antigos.** Depois de algumas semanas, volte em um projeto e tente melhorar a organização. É legal perceber a própria evolução.
